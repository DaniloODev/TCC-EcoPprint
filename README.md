# 📱 EcoPrint

EcoPrint é uma aplicação Full Stack [Web/Mobile] desenvolvida para democratizar o acesso à calculadoras de pegada de carbono, bem como criar laços e comunidades que apoiam projetos sustentáveis. O projeto integra uma interface responsiva com um banco de dados em tempo real.


## 🚀 Funcionalidades Principais
* **Autenticação de Usuários:** Login seguro e gerenciamento de sessões utilizando Firebase Auth.
* **Banco de Dados Real-time:** Sincronização de dados em tempo real entre todos os clientes conectados.
* **Interface Responsiva:** Design construído para rodar perfeitamente em dispositivos móveis e desktops.
* **Divulgação em tempo real de noticias relacionadas ao meio ambiente:** Foi feita uma integração de uma API que possui informações recentes relacionadas ao meio ambiente de fontes confiáveis.

## 🛠️ Stack Tecnológica
* **Frontend/Mobile:** JavaScript,  TypeScript, React, Ionic Framework, Angular, 
* **Backend/BaaS:** Node.js, Google Firebase (Firestore/Realtime DB)
* **Estilização:** CSS e SCSS
